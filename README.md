# Company Case Studies

A collection of company case studies, one topic per folder.

## Structure

```
<topic-name>/
  README.md      # the case study
```

## Workflow

- `main` is the default branch and holds only reviewed, merged work.
- Each topic is developed on its own branch (for example `topic/<topic-name>`).
- When a topic is ready, open a pull request into `main`, review it, and merge.
